python代码质量自动扫描工具，如果使用github，上传的代码也会被自动检查
1. 使用如下工具进行代码检查
   - mypy：查类型债
   - ruff：查 lint / format
   - pytest：查功能行为
2. 使用如下包进行包安全漏洞检查：对应github上Dependabot 的本地替代工具
   - pip-audit：PyPI 官方出品，扫描 Python 依赖漏洞
   - osv-scanner： Google 出品，直接解析依赖文件
3. GitHub Secret Scanning 的本地替代工具
   - gitleaks：最流行的开源密钥扫描器 支持 150+ 种密钥格式，熵值检测，可集成 pre-commit 
   - trufflehog: 另一个流行工具 支持验证密钥是否真实有效
   - detect-secrets: Yelp 出品 可生成基线文件，支持增量扫描
