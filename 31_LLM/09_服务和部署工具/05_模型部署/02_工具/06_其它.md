1. nano-vllm 
- Github (15.5k stars):https://github.com/GeeeekExplorer/nano-vllm
- 🚀 快速离线推理——与vLLM相当的推理速度

- ⚡ 优化套件——前缀缓存、张量并行、Torch编译、CUDA图等。

2. Minivllm
- Github (1k stars): https://github.com/Wenyueh/MinivLLM
- 基于Nano-vLLM，带有注意力机制基准的vLLM推理引擎的定制实现，但具备自包含的分页注意力和闪烁注意力实现。
- 在预填充时间内对闪烁注意力和解码时间内的分页注意力进行了基准测试。
